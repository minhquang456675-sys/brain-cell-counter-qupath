Brain Cell Counter v2.7.0 — Windows Installation Guide

Recommended approach: install the small core application first, then use the two automated dependency scripts. Install ABBA with its official standalone package because that package already includes Fiji, DeepSlice Local, Elastix and the ABBA environments.

1. Requirements

  • 64-bit Windows 10 or Windows 11.
  • At least 20 GB free disk space.
  • A stable internet connection for dependency installation.
  • For GPU Cellpose: an NVIDIA GPU and a current NVIDIA display driver. The CUDA Toolkit is not required.
  • Close QuPath before installation and before Brain Cell Counter batch analysis.

2. Install the Brain Cell Counter core

Double-click 01_Install_Core.cmd.

This copies the application to %LOCALAPPDATA%\BrainCellCounter and creates a desktop shortcut. It does not install or modify scientific dependencies.

3. Install QuPath and extensions

Double-click 02_Install_QuPath_and_Extensions.cmd.

The script downloads the official QuPath 0.7.0 portable archive and installs the compatible Cellpose, ABBA and Warpy extensions. Every download is pinned and checked using SHA-256. A QuPath desktop shortcut is created.

4. Install Miniforge and Cellpose

Double-click 03_Install_Miniforge_Cellpose.cmd.

The script installs Miniforge under %USERPROFILE%\miniforge3, creates the cellpose environment, installs Cellpose-SAM and downloads the approximately 1.2 GB cpsam_v2 model.

  • If nvidia-smi detects an NVIDIA GPU, CUDA 12.8 PyTorch wheels are installed.
  • If no NVIDIA driver is detected, CPU PyTorch is installed.
  • For an RTX 3050, install/update the driver from the official NVIDIA driver page before running this step.
This step can download several GB and may take 20–60 minutes. If it is interrupted, run the same file again; verified cached downloads are reused.

5. Install ABBA, Fiji and DeepSlice Local

Do not install a separate Fiji copy for this workflow. Download the official ABBA 0.11.0 Windows installer:

ABBA-Python-0.11.0-0.11.0-Windows-x86_64.exe

  1. Download the installer (approximately 1.9 GB).
  2. Run it and choose %LOCALAPPDATA%\ABBA-Python-0.11.0 as the destination.
  3. Keep the default components selected.
  4. Start ABBA once and allow Fiji components to finish downloading.
  5. Confirm that ABBA opens and that DeepSlice Local and Elastix are available.

Official SHA-256:

The official ABBA package contains Fiji, ABBA, BrainGlobe support, DeepSlice Local, Elastix and Transformix. The first launch still requires internet access to initialize Fiji files and download the chosen atlas.

6. Verify the installation

Double-click 04_Verify_Installation.cmd.

All rows should show PASS. The report is saved at %LOCALAPPDATA%\BrainCellCounter\Installation_Report.txt. For an NVIDIA machine, the Python check should contain "cuda_available": true and the GPU name.

7. First application run

  1. Open Brain Cell Counter from the Desktop. The application window should report v2.7.0.
  2. Open Settings.
  3. Confirm QuPath Console: %LOCALAPPDATA%\QuPath-0.7.0\QuPath-0.7.0 (console).exe.
  4. Confirm Cellpose Python: %USERPROFILE%\miniforge3\envs\cellpose\python.exe.
  5. Choose the ABBA/DeepSlice-exported project.qpproj.
  6. If stitched-image calibration is missing or unreliable, run CALIBRATE, review every scale bar, and apply only confirmed values before ABBA.
  7. Run PREFLIGHT, then VALIDATE.
  8. Only after validation is ready, run threshold optimization or ANALYZE.

Troubleshooting

  • Windows SmartScreen: select More info → Run anyway only if the package came from your trusted copy.
  • CUDA is false: update the NVIDIA driver, restart Windows, then rerun 03_Install_Miniforge_Cellpose.cmd.
  • GitHub download is blocked: connect to a network that permits GitHub release downloads, then rerun the same script.
  • QuPath extension is missing: close QuPath, rerun step 3, and reopen QuPath.
  • ABBA first launch is slow: allow it to complete the Fiji and atlas downloads without closing it.
  • Project images are missing: use Brain Cell Counter PREFLIGHT to locate moved source images and create a backed-up project repair.
